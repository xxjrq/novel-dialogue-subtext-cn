# 人物对白潜台词改稿

把小说里平直、同质的对白改得更有张力：输入对白片段、人物目的和关系，得到**不改动既有事实**的对白版本，以及逐句潜台词与人物差异说明。资料不够时会明确列出缺项，不把小说改成短剧剧本。

![人物对白潜台词改稿推广图](assets/promo-1600x900.png)

## 输入与结果

适合单个章节、场景或短文（表格最多 100 行）。输入包括：对白与说话人、每个人当下目标、人物关系、不可改变的事实或语气限制。结果包含改写对白、逐句“表层意思 / 潜台词策略 / 事实保留”表，以及人物语言差异核对；超长材料请分场景提交。

```bash
npx skills add xxjrq/novel-dialogue-subtext-cn
```

## 使用方式

直接粘贴材料，例如：

> 对白：林晏：“稿子你看完了吗？” 周宁：“看完了，没什么问题。”
> 林晏想确认对方是否发现自己的失误；周宁想让他自己承认。两人是资深编辑与新人。事实是周宁已读完且失误尚未说破。

输出会只在这些事实内改写，并解释每句的策略。完整可复制案例见：

- [成功样例](fixtures/success-example.md)
- [缺料样例](fixtures/failure-missing-input.md)

## 边界

- 不补造事件、人物关系或动机；缺少说话人、目的或关系就先索取材料。
- 不输出分镜、舞台指令或短剧格式。
- 仅处理用户提供的内容，不依赖浏览器、登录或第三方账号。
